# Keybinds

---

## Editor
#### Open editors
**`CTRL + 1 - 3`**

#### Close Editor
**`CTRL + SHIFT + W`**

#### File Search
**`CTRL + SHIFT + I`**

#### Symbol Search
**`CTRL + SHIFT + O`**

#### Option Search
**`CTRL + SHIFT + P`**

---

## Activity Bar
#### Toggle File Tree
 **`CTRL + SHIFT + E`**
#### Toggle Extensions
**`CTRL + SHIFT + X`**
#### Toggle Search 
**`CTRL + SHIFT + F`**

---

## Terminal
#### Toggle Bottom Terminal
**`CTRL + SHIFT + Ü`**

#### New Terminal
**`CTRL + SHIFT + Ö`**

#### Split Terminal
**`CTRL + SHIFT + 5`**

#### Switch Terminal
**`ALT + ARROW_KEY`**
